# 视觉资产规范

完整的生成、批量制作、检查、归档流程见 [image-asset-pipeline.md](image-asset-pipeline.md)。

## 资产分类

| 类型 | 典型用途 | 常见交付 |
|---|---|---|
| 功能/导航图标 | 菜单、按钮、状态、操作 | 统一图标库或独立 PNG/SVG |
| 业务图标 | 模块入口、业务卡片、指标类型 | 统一图标组 |
| 插画 | 欢迎区、功能介绍、引导、空状态 | PNG/WebP/SVG（按来源能力） |
| 背景图 | 登录页、Banner、首页头图区 | WebP/PNG |
| 装饰纹理 | 页面局部背景、分区氛围 | SVG/CSS 或优化后的图片 |
| 空状态图 | 无数据、未开通、无权限、异常 | 统一插画组 |

## 视觉职责

先明确素材要承担什么：品牌氛围、真实用户内容、功能入口、操作语义、空状态引导或局部材质。不要用场景图替代真实用户照片，也不要把所有模块都装饰成图片卡片。图像必须对品牌、信息理解或任务完成有实际价值。

## 资产选择决策

1. 搜索项目现有资产和图标依赖。
2. 判断是否符合业务语义、视觉质量、主题和尺寸要求。
3. 合适则复用；不合适或缺失则调用 Image 模型生成。
4. 对设计确实需要、但没有合适复用素材的图标、插画或背景图，必须使用 Image 生成。
5. 生成后检查质量、透明度、裁切、边缘、尺寸和主题适配。
6. 优化压缩并登记到资产清单；批量生成时确保共同笔触、光照、比例、留白与命名规则。

## 不允许使用符号代替图标

Emoji、Unicode 图形符号、ASCII 字符、字母缩写、彩色圆点、空心方块、加减号、箭头字符等，均不可作为正式 UI 图标。文字按钮中的正常文案不受此限制；这里禁止的是用字符充当图形图标。

如果已有图标库可复用，按现有图标库规范使用；如果没有合适的图标资产，必须用 Image 生成。如果图像生成能力不可用，应将该项标记为阻塞并说明，不得伪造资产或用字符替代。

## 图标一致性

同一产品内保持一致的：
- 线条粗细、端点、圆角和填充方式。
- 视觉重心、画布尺寸和安全边距。
- 色彩、明暗、阴影、透视和复杂度。
- 默认、激活、禁用、深色背景等状态。

功能图标应可辨识且不过度装饰。小尺寸显示时应优先保证轮廓清晰。Image 生成的图标可在不损失设计特征的前提下转为 SVG；保留原始生成文件和来源记录。

## 背景与插画使用原则

- 背景图必须服务于品牌表达、信息层级或业务语境，不能为了“有背景”而强行添加。
- 高密度表格、表单和复杂数据区通常不铺大面积背景图。
- 背景图应预留文字安全区，避免主体被标题或按钮遮挡。
- 不要在生成图中包含真实文字、Logo、按钮或伪造的页面控件。
- 需要 PC 与移动端不同构图时分别生成。
- 前景文字和业务控件必须用真实前端代码实现。
- 图片需适当压缩、懒加载和设置尺寸，避免布局抖动及性能退化。

## 工程使用

- 图片不应成为点击命中的唯一依据；实际交互由 HTML 控件承担。
- 用户上传的照片、业务附件和证据材料不得由生成图冒充。
- 保留原始生成素材，优化后文件另存，不覆盖来源文件。
- 设置尺寸/宽高比，按需加载，避免图片造成布局抖动。

## 资产登记字段

资产名称、文件路径、类型、使用场景、关联页面、来源（复用/生成）、生成模型（如可获得）、提示词、尺寸、格式、主题适配、是否可复用、替代旧资产说明。
