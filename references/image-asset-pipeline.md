# Image 视觉资产生成与交付流水线

## 目标

把图片从“临时装饰”变成有语义、有一致性、可复用、可追溯的产品资产。资产选择先看职责和质量，再决定复用或生成。

## 1. 按视觉职责选资产

| 视觉职责 | 优先资产 | 设计要求 |
|---|---|---|
| 品牌氛围/场景 | 摄影、抽象背景、场景图 | 文字安全区、移动裁切和对比度 |
| 用户内容 | 用户真实上传的照片/文件 | 不用生成图冒充真实用户内容 |
| 功能入口/业务分类 | 成套图标或插画 | 语义清楚、风格统一、小尺寸可辨识 |
| 高频操作/状态 | 现有统一图标库；缺失时生成图标资产 | 熟悉语义、尺寸一致、触控区独立 |
| 空状态/引导 | 专项插画 | 表达状态和下一步，不只是装饰 |
| 材质/局部氛围 | 纹理、边饰、局部背景 | 不遮挡内容、焦点或可点击区域 |

## 2. 决策顺序

1. 盘点项目已有资产、图标库、品牌规范和许可证/来源。
2. 判断候选资产是否匹配用途、语义、风格、质量、尺寸、明暗主题和性能。
3. 合适则复用；不合适或缺失时，对确实需要的素材调用 Image 生成。
4. 同一批资产先定义共同风格，再批量生成，避免逐个生成造成笔触和光照漂移。
5. 生成后检查透明通道、边缘、留白、裁切、比例、清晰度和小尺寸表现。
6. 保留原始生成文件，按实际展示尺寸优化导出格式和文件体积。
7. 登记文件名、用途、来源、提示词、模型、尺寸、主题适配、页面引用和复用状态。

## 3. 成套图标与插画

提示词明确：
- 产品语境和每个资产的语义职责。
- 主风格、色彩、线条/填充、光照和透视。
- 相同画布尺寸、视觉重心、安全留白。
- 透明背景或干净背景的要求。
- 不含文字、字母、数字、水印、伪造 Logo 或 UI 控件。
- 图集时明确行列、格子顺序和等尺寸单元，检查每格边界和拆分结果。

不要用 Emoji、Unicode 符号、ASCII 字符或 CSS 伪元素字符冒充正式图标。已有合适图标库可复用；缺少合适图标时按本 Skill 的强制规则使用 Image 生成。Image 工具不可用时如实标记阻塞，不得用字符绕过。

## 4. 背景图和内容图

- 背景图应明确主体位置、文字安全区、裁切范围、明暗对比和目标视口。
- PC 与移动端构图不同且无法兼容时分别生成，不要强行拉伸。
- 不把真实文案、数字、表单、按钮、Logo 或整张假网页烘焙进背景。
- 图片不应成为点击命中的唯一区域；交互必须由真实前端元素承担。
- 用户照片、证据图片、业务附件等真实内容不得用生成图替换。
- 图片加载失败时，仍要保留内容语义、布局和可访问说明。

## 5. 格式与工程

- 沿用项目现有资产目录和图片组件。
- 文件名语义化，避免覆盖已有源文件。
- 优化 WebP/AVIF/PNG/SVG 等格式时按透明度、清晰度、兼容性和项目工具链选择。
- 设置宽高或 aspect-ratio，避免布局抖动；大图按需加载。
- 记录来源和许可要求；外部素材应确认可复用条件和必要署名。
- 不要为了“视觉丰富”把图片铺满每个模块；图片必须有品牌、信息或任务价值。
