# Image 视觉设计提示词手册

## 通用原则

向 Image 模型提供明确的业务背景、用户任务、参考截图、视口比例、视觉方向、必须保留的内容和禁止项。避免只说“做得高级一点”“更有设计感”。

## A. 已有页面重设计模板

```text
请基于我提供的当前页面截图，重新设计一个可实际落地的高保真 Web UI。

业务目标：{本次要解决的问题}
目标用户：{角色}
核心任务：{用户在页面上要完成什么}
必须保留：{功能入口、字段、数据、业务流程}
允许调整：{布局、层级、配色、卡片、导航、视觉资产等}
不可改变：{API、路由、权限、业务规则等}
目标视口：{例如 1440x900}

设计要求：
- 保留必要业务信息和操作，不擅自删除功能。
- 明确视觉层级、信息密度、网格、间距和排版。
- 采用统一的图标、插画和背景视觉语言。
- 需要图标或背景时，设计真实可拆分的视觉资产，不要用 Emoji 或字符代替。
- 不生成假浏览器边框、假 Logo、乱码文字或整页截图式背景。
- 页面必须能由 HTML/CSS/组件实现，交互控件形态清楚。
- 输出完整页面构图，不能只画局部 Banner。
```

## B. 从零设计模板

```text
请根据以下业务需求设计一个高保真 Web UI 概念稿。

产品/模块：{名称}
用户角色：{角色}
业务目标：{目标}
核心任务：{任务列表}
页面内容：{信息架构}
主要操作：{操作}
数据密度：{低/中/高及示例}
终端与视口：{PC / H5 / 移动端}
品牌约束：{颜色、Logo、行业属性}

请优先保证业务流程清晰、信息层级明确、视觉精致、组件统一和响应式可实现。
为需要的图标、插画、背景图和空状态建立统一风格，不要用字符或 Emoji 代替图标，不要在生成图里写大量真实文案。
```

## C. 生成一组统一图标模板

```text
生成一套用于同一个企业 Web 产品的图标资产。
图标主题：{功能列表}
风格：{线性/面性/双色/轻 3D，选定一种主风格}
统一要求：相同画布尺寸、视觉重心、线条粗细、圆角、透视、光照和主辅色。
每个图标单独、完整、居中，四周留白一致；透明背景优先；不要文字、字母、数字、水印、边框或多余装饰。
输出应便于裁切成独立 PNG 资产，并在 16/20/24/32px 等小尺寸检查清晰度。
```

## D. 生成背景图模板

```text
为 {页面/模块} 生成可用于真实 Web 产品的背景视觉资产。
画布比例：{16:9 / 3:1 / 4:5 等}
主题：{业务主题}
主体位置：{左/右/居中/边缘}
文字安全区：{明确区域，保持低细节和足够对比}
色彩：{品牌色与辅助色}
风格：{抽象科技/柔和纹理/行业场景/轻插画}
禁止：文字、Logo、按钮、假 UI、二维码、水印和过强高频细节。
需要考虑 PC 和移动端裁切；若构图无法兼容，应分别生成。
```

## E. 生成后检查

- 构图和内容是否符合需求？
- 是否包含错误文字、假 Logo、水印或多余控件？
- 是否能在目标尺寸清晰显示？
- 透明背景、裁切和留白是否合格？
- 同一套资产风格是否一致？
- 是否已保存到项目资产目录并登记？
