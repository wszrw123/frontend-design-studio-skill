# 使用示例

## 已有页面改造

> 使用 frontend-design-studio。先理解本次优化目标，再获取当前页面真实截图并分析源码。以当前截图为参考调用 Image 生成完整高保真重设计稿；盘点公共组件和现有视觉资产，没有合适可复用图标、背景图或插画时必须使用 Image 生成，禁止用字符或 Emoji 代替。按设计稿实施代码，保留原业务逻辑，并对相关页面进行真实浏览器视觉与交互验收。

## 从零设计

> 使用 frontend-design-studio。根据以下业务需求先整理页面信息架构，再调用 Image 生成高保真页面方案。随后拆解 Design Tokens、公共组件、页面模式和视觉资产，按当前项目技术栈实现，并完成 PC/移动端真实页面验收。

## 公共组件升级

> 使用 frontend-design-studio。先检索该组件所有引用页面和现有变体，判断是否应升级已有公共组件。先通过 Image 设计目标样式，再实现组件改造；逐一检查主要引用页面，避免只在当前页面通过。
